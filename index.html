Course Overview

This course covers fundamental data structures and algorithms used in modern software systems. We focus on how to model data, choose appropriate structures, and analyze the efficiency of operations using Big-O notation.

Lecture slides, Jupyter notebooks, and interactive guides are published in this repository and linked from the course outline below.
